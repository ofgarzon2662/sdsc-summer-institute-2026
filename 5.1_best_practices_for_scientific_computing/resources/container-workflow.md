# Historical container reference

Containers are not part of the 2026 skydiver tutorial or live deployment
example. Students will publish a Python wheel to PyPI and install it directly
into an Expanse virtual environment instead.

This file remains only to explain why the repository still contains a Dockerfile
and container-oriented SLURM examples from earlier material. Do not use those
files for the current session. Use
[PyPI and Expanse workflow](expanse-pypi-workflow.md) instead.
